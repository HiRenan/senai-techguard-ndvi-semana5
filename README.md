# senai-techguard-ndvi-semana5

Atividade da Semana 5 do projeto Americas TechGuard (SENAI): analise de NDVI e relacao com risco de inundacao.

## Estrutura
- `NDVI_implementation/NDVI_Semana5_final.ipynb`: notebook final (em portugues).
- `NDVI_implementation/src/`: imagens de apoio e entrada raster local.
- `NDVI_implementation/output/`: mapa, histograma e estatisticas geradas.

## Observacao sobre dados raster
O arquivo `.tif` principal pode ser grande e exceder o limite do GitHub (100 MB).  
Por isso, os `.tif` em `NDVI_implementation/src/` ficam fora do versionamento.

Coloque seu raster local em:
`NDVI_implementation/src/`

Nome sugerido:
`QE_2024-09-20.tif`
